# Project Context: Parameter-Efficient UI Code Generation (ISASF 2026, Paper 132)

This file records everything needed to understand, reproduce or continue this project after the local
working folder is gone. It was written when the paper was accepted and presented (November 2026).

## 1. What the project is

**Paper:** "Parameter-Efficient UI Code Generation Using QLoRA on an Extended WebSight Dataset"
**Authors:** Aniruddha Dev Nath, Anitya Barua, Antu Chowdhury (East Delta University); Arnab Biswas
(International Islamic University Chittagong). Dept. of Computer Science and Engineering, Chattogram, Bangladesh.
**Venue:** ISASF 2026, International Conference on Intelligent Sensing and Autonomous Systems for Sustainable
Future, 19 November 2026 (hybrid), Western Sydney University; organised by Amity University. Paper ID 132.
Camera-ready footer: `979-8-3195-3350-0/26/$31.00 ©2026 IEEE`.

**Idea:** extend WebSight (screenshot + HTML) with React JSX and Vue 3 SFC targets generated by
Qwen2.5-Coder-7B and checked by production parsers; fine-tune small vision-language models with QLoRA on a
single 8 GB consumer GPU (RTX 3070 Ti) to generate HTML, JSX or Vue from a screenshot.

## 3. Final results (all numbers are in `paper.tex` and `finetuning/results/`)

WebSight test set, 1,488 samples (496 images x HTML/JSX/Vue), mean over the three tasks:

| Metric | Base 2B (zero-shot) | Qwen2.5-VL-3B (zero-shot) | QLoRA 2B | QLoRA 3B (1 epoch) |
|---|---|---|---|---|
| SSIM | 0.509 | 0.711 | **0.716** | **0.716** |
| PSNR (dB) | 8.43 | 11.56 | **12.09** | 11.94 |
| LPIPS (lower better) | 0.681 | 0.563 | **0.515** | 0.524 |
| PSR (%) | 96.24 | 99.46 | **99.93** | **99.93** |
| BLEU-4 | 52.24 | 54.31 | **80.73** | 78.41 |
| CodeBLEU | 0.520 | 0.575 | **0.735** | 0.713 |

Key statements (keep these honest in any future writing):
- SSIM of QLoRA 2B is **statistically tied** with zero-shot 3B (p = 0.33) and with QLoRA 3B (p = 0.87).
  LPIPS and PSNR are significantly better than zero-shot 3B. Reference-code SSIM ceiling: 0.722.
- QLoRA 2B vs QLoRA 3B: 2B slightly better on LPIPS (-0.009 [-0.015, -0.003]), PSNR (+0.15 dB [0.01, 0.30]),
  BLEU-4 (+2.3 [1.6, 3.0]), CodeBLEU (+0.022 [0.015, 0.028]). The 3B had 1 epoch (3,152 steps, ~34 h), BF16.
- Controlled latency (same 24 samples, batch 8): base 2B 6.4 s / 4.59 GiB; QLoRA 2B 11.2 s / 2.18 GiB;
  QLoRA 3B 12.9 s / 3.30 GiB; zero-shot 3B 22.9 s / 6.47 GiB. **4-bit saves memory, not time**
  (1.75x slower than 16-bit base).
- Design2Code (100 random real pages, first-screen 16:9 crop): QLoRA 2B +0.210 SSIM over base [0.183, 0.239],
  p < 0.001; tied with QLoRA 3B (p >= 0.08) and, on 25 pages, with zero-shot 3B. Outputs ~600 tokens vs a
  real-HTML median of 14,805 tokens.
- Dataset: 15,752 processed; JSX valid 15,750; Vue valid 15,590; both valid 15,588 (98.96%); PABAK 0.9786;
  render check on 2,000 images: JSX 99.5% / Vue 100% render, median SSIM 0.90 / 0.96.

## 5. Important technical gotchas

- **CodeBLEU depends on Python's hash seed** (its data-flow match iterates over sets): JSX CodeBLEU moved up to
  0.01 between runs. All CodeBLEU values use `PYTHONHASHSEED=0` (`recalc_codebleu_seeded.py`; `bootstrap_ci.py`
  pins it for its workers).
- **Design2Code renders vary slightly between runs** (real pages load external fonts/images). All Design2Code
  numbers come from one final run (`results/design2code_per_sample.json`).
- **Image tokens**: we set the Qwen2-VL processor to 256-512 visual tokens (`min_pixels=256*28*28`,
  `max_pixels=512*28*28` in `train.py`/`evaluate.py`); this is our setting, not the default.
- **3B training**: FP16 caused NaN-skipped steps, so BF16; paged 8-bit AdamW and 16-bit frozen embeddings to fit
  8 GB; LoRA excluded from the vision tower (`exclude_modules=".*visual.*"`). Neither model has adapters in the
  vision encoder (verified: 0 visual tensors).
- **Environment**: use `py -3.10` (the `.venv311` env is broken). Playwright/Chromium only works when launched from
  PowerShell, not Git Bash. Run `npm ci` in `finetuning/` before validation (JSX/Vue parsers are Node packages).
- **Git**: the folder was created by another Windows user, so git needs
  `git -c "safe.directory=E:/Thesis Project file" ...` (or a global safe.directory entry).
- **LaTeX**: IEEEtran + BibTeX via MiKTeX; IEEEtran lowercases titles, so acronyms in `custom.bib` are braced.

`scratchpad` folder); edit them before running elsewhere.

|---|---|

| Presentation | `tools/build_deck.py` fills the ISASF template (verifies 72 numbers against `paper.tex` first); `tools/make_short.py` makes the 5-minute version. Slide structure was created with the pptx skill's `add_slide.py`. |

WebSight), then `python finetuning/train.py --method qlora` (2B) or `--method qlora_3b`. To re-evaluate without
retraining, load the adapters from the backup zip with `evaluate.py --method qlora` / `qlora_3b`.
